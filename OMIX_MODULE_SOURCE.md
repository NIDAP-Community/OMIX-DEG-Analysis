# Canonical OMIX module

The canonical scientific source for this deployment repository is
[OMIX-DEG-Analysis](https://github.com/NIDAP-Community/OMIX/tree/main/modules/OMIX-DEG-Analysis)
in the OMIX monorepo.

This repository owns deployment-specific UI, input discovery, and runtime
configuration. Reusable scientific behavior belongs in the canonical module.
See the monorepo [module contract](https://github.com/NIDAP-Community/OMIX/blob/main/docs/module-contract.md)
before changing shared behavior.
